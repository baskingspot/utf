# Validation: UTF-8, ASCII, UTF-16, UTF-32, 2026-10-31

The wave-1 validators in `src/validate.zig` against simdutf, Rust, Go, and Zig's std (`just bench-compare`), and the A/Bs behind each choice in them. Every number here is from one machine and one sitting; compare within a table, not across tables.

- Machine: Amp orb, KVM guest, Intel Xeon @ 2.60GHz (Ice Lake server, family 6 model 106, AVX-512 with VBMI2), 4 vCPUs (2 cores, 2 threads each).
- Zig 0.16.0 ReleaseFast. `-Dcpu=native` selects the AVX-512 path, `x86_64_v3` AVX2, `x86_64_v2` SSE, `baseline` the generic path.
- Arms comparison: `just bench-compare 6 validate-utf8 validate-utf8-err` on the tree before the last commit (`validate: skip ASCII before rerunning the scalar validator on an error`), whose A/B below has the one row it moves; pinned to CPU 3, simdutf 9.2.1 with its `icelake` kernel.
- A/Bs: a scratch testingx suite outside the repository (source at the end), because the harness has no UTF-16, UTF-32, or ASCII operations and no sizes between its corpus files. Each A/B builds both versions, alternates them run by run on one core (CPU 2 or 3), and compares with benchstat. Inputs are 16 bytes past a 64-byte boundary from the ASCII-loop A/B on, as the harness's are.

## Takeaways

- Non-ASCII UTF-8 (the eight non-Latin scripts): 23.0–25.5 GB/s, 1.10–1.22× simdutf (20.5–21.0) and 1.39–1.54× Rust's `simdutf8` (16.5–16.7). The checked form, on input with an error in its last character, is 22.3–25.3 GB/s, 1.20–1.45× simdutf.
- Long ASCII: 223 GB/s at 4 KiB (simdutf 86, Rust 86); 95–98 GB/s at 64 KiB and 1 MiB and on the Latin corpus, which is 3–7% under simdutf (99–102) in the plain form and above every arm except Rust's checked form (125–126) in the checked one.
- Short ASCII: 3.6 GB/s at 16 bytes, level with simdutf and 0.68× Rust (5.3); 14.3 at 64, 0.62× Rust (23.2) and 0.76× std (18.8); 52.6 at 256, 0.85× Rust (61.7). The best arm per row is still Rust below 4 KiB. The remaining cost is call overhead and the short-input branches, not the block loop; wave 2.
- Checked form on short ASCII inputs that end in an error: 1.16 GB/s at 16 bytes in the arms run, under std (1.77) and Rust (1.84), simdutf 0.11; skipping ASCII before the scalar rerun takes it to 1.73 in its own A/B (+50%). 4.7 GB/s at 64 and 17.5 at 256, where Rust does 5.3 and 19.6.
- Peak RSS: 2.5 MiB, the same as Zig std, which is the floor (the inputs plus the process); simdutf 6.1, Rust 3.9, Go 4.4. Validation allocates nothing.
- ISA paths, UTF-8 at 4 KiB–1 MiB of CJK and emoji: AVX-512 21–23 GiB/s, AVX2 14–15.5, SSE 9, generic 1.3 (the scalar validator after the ASCII prefix). Long ASCII is 80–150 GiB/s on all four.
- UTF-16LE 72–83 GiB/s on BMP text and 48–51 on emoji (all surrogate pairs), UTF-32 89–94, ASCII 89–153, from 4 KiB; 10–40× the scalar validators.
- Correctness: `just oracle` (1,638,976 UTF-8 inputs under simdutf's `icelake` kernel and again under `fallback`) and `oracle-compare 4000000 7` (4,638,976 UTF-8 and 1,000,000 UTF-16LE inputs): 0 mismatches in error kind or position for `validate.utf8`, `validate.utf8WithErrors`, and `validate.utf16leWithErrors`.

## Choices, and the A/B behind each

### Short inputs: the padded block in registers

Below 64 bytes the input is zero-padded into one block. Built in a stack buffer with two overlapping copies (`stack`), the 64-byte load of it stalls store-to-load forwarding; built in registers from 16-byte loads and a tail of overlapping integer loads (`registers`, `simd.loadPartial`), it is 2.1× as fast at every short size. AVX-512, before the inputs were offset.

### ASCII first

Below 64 bytes, an ASCII check on overlapping loads before the padded block; from 64 bytes, a loop over leading ASCII blocks before the UTF-8 loop, so ASCII text never loads the lookup tables (`ascii-first`). ASCII gains 19–67%; non-ASCII text of exactly 64 bytes loses 6–10%, about 0.5 ns, because its first block is tested for ASCII twice. AVX-512.

### The bytes one to three back: shifts or loads

The paper's form shifts the previous block's last bytes in (`shift`, `simd.prev`: `valignq` plus three `vpalignr` on AVX-512, all on port 5). The alternative loads them from memory at offsets -1, -2, -3 (`load`). Loads win on AVX2 (+9–13% from 4 KiB) and SSE (+12–20%) and lose on AVX-512 (-5 to -13%), where every 64-byte load at those offsets splits a cache line. `prev_by_load` picks loads on AVX2 and SSE only. NEON and the generic path keep the shifts, unmeasured.

## The scratch suite

`bench.zig`, with a `build.zig` that imports the package from a source path (`-Dsrc`) so two trees can be built side by side, and testingx's `addBenchExe`. The `shortscalar` arm was the plan's other short-input candidate (skip ASCII a word at a time, then the scalar validator); the in-register padded block beat it on every non-ASCII row from 16 bytes.

```zig
//! Validation throughput: utf (SIMD), the scalar reference, and std.
const std = @import("std");
const testingx = @import("testingx");
const utf = @import("utf");
const B = testingx.B;

const texts = .{
    .{ "ascii", "The quick brown fox jumps over the lazy dog. Pack my box with five dozen liquor jugs! 0123456789 " },
    .{ "latin", "Le cœur a ses raisons que la raison ne connaît point. Où êtes-vous allés? Ça va très bien, merci. Die Größe der Bäume überrascht. " },
    .{ "arabic", "اللغة العربية هي إحدى أكثر اللغات انتشاراً في العالم، يتحدثها أكثر من ٤٢٢ مليون نسمة. " },
    .{ "chinese", "中文是世界上使用人数最多的语言之一，汉字有着悠久的历史和丰富的文化内涵。" },
    .{ "hindi", "हिन्दी विश्व की एक प्रमुख भाषा है और भारत की राजभाषा है। " },
    .{ "emoji", "😀😃😄😁😆😅🤣😂🙂🙃😉😊😇🥰😍🤩😘😗☺😚😙🥲😋😛😜🤪😝🤑🤗🤭" },
};
const sizes = [_]usize{ 8, 16, 32, 48, 64, 256, 1024, 4096, 65536, 1 << 20 };

var inputs: [texts.len][sizes.len][]u8 = undefined;
var inputs16: [texts.len][sizes.len][]u16 = undefined;
var inputs32: [texts.len][sizes.len][]u32 = undefined;

/// `size` bytes of repeated `seed`, cut at a character boundary and padded
/// with spaces, so every input is valid.
fn makeText(a: std.mem.Allocator, seed: []const u8, size: usize) ![]u8 {
    // 16 bytes past a 64-byte boundary, as the harness's inputs can be.
    const buf = (try a.alignedAlloc(u8, .@"64", size + 16))[16..];
    var i: usize = 0;
    var j: usize = 0;
    while (true) {
        const n = std.unicode.utf8ByteSequenceLength(seed[j]) catch unreachable;
        if (i + n > size) break;
        @memcpy(buf[i..][0..n], seed[j..][0..n]);
        i += n;
        j = (j + n) % seed.len;
    }
    @memset(buf[i..], ' ');
    return buf;
}

pub fn benchmarkMain(b: *B) !void {
    @setEvalBranchQuota(100_000);
    const a = std.heap.page_allocator;
    inline for (texts, 0..) |t, ti| {
        for (sizes, 0..) |size, si| {
            inputs[ti][si] = try makeText(a, t[1], size);
            // UTF-16 and UTF-32 of the same text, sized in bytes too.
            const u16s = try a.alloc(u16, size / 2);
            const text16 = try makeText(a, t[1], size);
            var n: usize = 0;
            var it = std.unicode.Utf8View.initUnchecked(text16).iterator();
            while (it.nextCodepoint()) |cp| {
                if (cp >= 0x10000) {
                    if (n + 2 > u16s.len) break;
                    const c = cp - 0x10000;
                    u16s[n] = @intCast(0xD800 + (c >> 10));
                    u16s[n + 1] = @intCast(0xDC00 + (c & 0x3FF));
                    n += 2;
                } else {
                    if (n + 1 > u16s.len) break;
                    u16s[n] = @intCast(cp);
                    n += 1;
                }
            }
            @memset(u16s[n..], ' ');
            inputs16[ti][si] = u16s;
            const u32s = try a.alloc(u32, size / 4);
            var m: usize = 0;
            it = std.unicode.Utf8View.initUnchecked(text16).iterator();
            while (m < u32s.len) : (m += 1) u32s[m] = it.nextCodepoint() orelse ' ';
            inputs32[ti][si] = u32s;
            std.debug.assert(utf.scalar.validateUtf8(inputs[ti][si]).err == .none);
            std.debug.assert(utf.scalar.validateUtf16le(u16s).err == .none);
            std.debug.assert(utf.scalar.validateUtf32(u32s).err == .none);
        }
    }
    inline for (texts, 0..) |t, ti| {
        inline for (sizes, 0..) |size, si| {
            const prefix = "/text=" ++ t[0] ++ std.fmt.comptimePrint("/size={d}", .{size});
            inline for (.{ "utf", "scalar", "std", "shortscalar" }) |impl| {
                if (comptime std.mem.eql(u8, impl, "shortscalar") and size >= 64) continue;
                try b.add("ValidateUtf8" ++ prefix ++ "/impl=" ++ impl, Utf8(ti, si, impl).run);
            }
            if (comptime std.mem.eql(u8, t[0], "ascii")) {
                inline for (.{ "utf", "scalar" }) |impl| try b.add("ValidateAscii" ++ prefix ++ "/impl=" ++ impl, Other(ti, si, impl, .ascii).run);
            }
            if (size >= 64 and (comptime std.mem.eql(u8, t[0], "latin") or std.mem.eql(u8, t[0], "chinese") or std.mem.eql(u8, t[0], "emoji"))) {
                inline for (.{ "utf", "scalar" }) |impl| {
                    try b.add("ValidateUtf16le" ++ prefix ++ "/impl=" ++ impl, Other(ti, si, impl, .utf16).run);
                    try b.add("ValidateUtf32" ++ prefix ++ "/impl=" ++ impl, Other(ti, si, impl, .utf32).run);
                }
            }
        }
    }
}

/// The plan's other short-input candidate: skip ASCII a word at a time, then
/// the scalar validator.
fn shortScalar(bytes: []const u8) bool {
    var i: usize = 0;
    while (i + 8 <= bytes.len) : (i += 8) {
        if (std.mem.readInt(u64, bytes[i..][0..8], .little) & 0x8080808080808080 != 0) break;
    }
    while (i < bytes.len and bytes[i] < 0x80) i += 1;
    return utf.scalar.validateUtf8(bytes[i..]).err == .none;
}

fn Utf8(comptime ti: usize, comptime si: usize, comptime impl: []const u8) type {
    return struct {
        fn run(b: *B) !void {
            const in = inputs[ti][si];
            b.setBytes(@intCast(in.len));
            var ok: usize = 0;
            defer b.keepAlive(ok);
            while (try b.loop()) {
                var p: []const u8 = in;
                std.mem.doNotOptimizeAway(&p);
                const r = if (comptime std.mem.eql(u8, impl, "utf"))
                    utf.validate.utf8(p)
                else if (comptime std.mem.eql(u8, impl, "scalar"))
                    utf.scalar.validateUtf8(p).err == .none
                else if (comptime std.mem.eql(u8, impl, "std"))
                    std.unicode.utf8ValidateSlice(p)
                else
                    shortScalar(p);
                ok += @intFromBool(r);
            }
            if (ok == 0) return b.fail();
        }
    };
}

fn Other(comptime ti: usize, comptime si: usize, comptime impl: []const u8, comptime kind: enum { ascii, utf16, utf32 }) type {
    return struct {
        fn run(b: *B) !void {
            var ok: usize = 0;
            defer b.keepAlive(ok);
            const simd = comptime std.mem.eql(u8, impl, "utf");
            switch (kind) {
                .ascii => {
                    const in = inputs[ti][si];
                    b.setBytes(@intCast(in.len));
                    while (try b.loop()) {
                        var p: []const u8 = in;
                        std.mem.doNotOptimizeAway(&p);
                        ok += @intFromBool(if (simd) utf.validate.ascii(p) else utf.scalar.validateAscii(p).err == .none);
                    }
                },
                .utf16 => {
                    const in = inputs16[ti][si];
                    b.setBytes(@intCast(in.len * 2));
                    while (try b.loop()) {
                        var p: []const u16 = in;
                        std.mem.doNotOptimizeAway(&p);
                        ok += @intFromBool(if (simd) utf.validate.utf16le(p) else utf.scalar.validateUtf16le(p).err == .none);
                    }
                },
                .utf32 => {
                    const in = inputs32[ti][si];
                    b.setBytes(@intCast(in.len * 4));
                    while (try b.loop()) {
                        var p: []const u32 = in;
                        std.mem.doNotOptimizeAway(&p);
                        ok += @intFromBool(if (simd) utf.validate.utf32(p) else utf.scalar.validateUtf32(p).err == .none);
                    }
                },
            }
            if (ok == 0) return b.fail();
        }
    };
}
```
